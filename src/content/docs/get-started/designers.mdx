## How to use
- Open it in a separate file or add your designs directly to copy of the community file.
- If you have a paid Figma account, you can also use the community file as a library.

## Components

- Use the 'Assets' panel to browse and search the available components.
- Add an instance of the component into your designs.
- Use the property panel on the right to customize the component to fit your requirements.
