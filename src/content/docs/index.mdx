## What is Digital Design Nizam

Digital Design Nizam is an open-source design system for making citizen-centric digital products for Pakistani audience. 

A design system is a collection of reusable components, guided by clear standards, that can be assembled together to build any number of applications. For a government, a well-crafted design system can help ensure consistent, accessible, and user-friendly digital experiences across all citizen-facing services and applications.

It is intended for designer and developer working on apps, websites, softwares for the government, public sector, development sector and civic tech projects.

### What makes it unique

👈 Components built with Right-to-left and local languages support out of the box

✋ Built with a focus on accessibility and usability for all

🇵🇰 Adopting Pakistani identity into the user interface

📱 Built on top of TailwindCSS to be used with modern technology stacks


## About the project

At <a href="https://codeforpakistan.org" target="_blank">Code for Pakistan</a>, we are developing a design system that has the potential to become the standard for all digital services in Pakistan. Currently, it is used internally for building digital products for various government departments and the public. We also advocate for its adoption by technology units within the government.

Governments exist to serve their people, and a strong design system helps them do that more effectively.
